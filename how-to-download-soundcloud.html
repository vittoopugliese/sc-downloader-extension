How to Download SoundCloud Tracks, Playlists & Likes

Updated: September 2026 — The downloader is free: save public SoundCloud tracks, playlists, albums, likes and artist uploads without a SoundCloud login for public pages. Player Tools is optional and has separate trial and Pro limits explained below.

Ready to start downloading?

Install Free Chrome Extension

Download Single SoundCloud Tracks

  1. Install the SoundCloud Track Downloader extension
  2. Go to any SoundCloud track page (e.g., soundcloud.com/artist/track-name)
  3. Use the orange download button in the action bar (next to Like/Repost/Share), the extension popup, or the white download button inside Player Tools.
  4. Choose Auto, MP3 or M4A when those source options are available, and optionally choose a destination folder.
  5. The track saves with available cover art and metadata. If no folder was chosen, Chrome uses its normal Downloads folder.

Download SoundCloud Playlists in Bulk

  1. Open any SoundCloud playlist or album page
  2. Click the extension icon or use the inline download button
  3. Choose how many tracks: 10, 25, 50, 100, 200, or All
  4. Select your download folder (optional)
  5. Click Download — files save automatically as they complete

Pro tip: You can close the popup or switch tabs. Downloads continue in the background; pause, resume or cancel from the extension, and follow progress on its badge.

Download Your SoundCloud Likes

  1. Go to soundcloud.com/you/likes (requires login)
  2. Or visit any user's public likes page: soundcloud.com/username/likes
  3. Click the download button and select the number of tracks
  4. All liked tracks download to a numbered folder

Download All Tracks from a SoundCloud Artist

  1. Visit soundcloud.com/artist-name/tracks
  2. Click "Download tracks" button
  3. Select which tracks you want from the list
  4. Start bulk download

What Is Free

  • Downloads forever — Individual tracks, playlists, albums, public likes and public artist uploads. Downloading full tracks and collections is never a paid feature.
  • Bulk and background downloads — Choose individual tracks or a whole collection; batches can keep running after you close the popup or change tabs.
  • Three entry points — Use the popup, an inline SoundCloud action-bar button, or the Player Tools download button for the currently playing track.
  • File handling — Available source formats, cover art, metadata, numbered collection folders, and an optional remembered destination folder.
  • No login for public pages — Sign in to SoundCloud only when the page itself requires it, such as your private likes.
  • Sampler pads — Trigger the included pads or load your own compatible audio samples while listening.

Player Tools: Trial vs. Pro

Player Tools is optional. Opening its eligible surfaces starts a 7-day trial for the current Chrome profile. During that trial you can create up to 20 new A–B loops total, shared across tracks and tabs; the allowance does not reset monthly. The extension does not require an account or fingerprint the browser, so this trial is not described as reinstall-proof.

  • Included in the trial — Playback speed from 0.1x to 3x, Keep Tone, two saveable speed presets, A–B listening, visual range editing, waveform zoom, reverb and delay FX.
  • Player Tools Pro — USD 3.69, one-time lifetime payment — Unlimited loops; editable loop timestamps and precise marker nudges; WAV export of an A–B range; full-track export with supported playback transformations and FX; parametric EQ (up to eight points, high/low-pass filters and optional hard clipping); and Likes Explorer.
  • Still free after the trial — Standard, unprocessed full-track and collection downloads. Pro never gates the downloader itself.

Use Player Tools

  1. Open a SoundCloud track and press the speedometer in the persistent player controls.
  2. Set a speed between 0.1x and 3x. With Keep Tone off, pitch follows speed (use a faster setting for a nightcore-style sound); with it on, duration changes while musical pitch is preserved.
  3. Use Set A and Set B or the waveform handles to repeat a passage. Scroll over the waveform to zoom, and use the sampler or FX panels while listening.
  4. With Pro, refine the timestamps, shape sound with parametric EQ, export the selected loop as WAV, or save the whole current track with its supported active transformations.

Audio Quality & Formats

The extension downloads tracks in their available streaming quality:

  • AAC HLS 160k — SoundCloud's standard streaming format (~50-80 MB/hour)
  • Original files — When artists enable downloads, you get WAV/FLAC/high-quality MP3
  • No artificial quality loss or re-encoding

Troubleshooting Common Issues

Extension doesn't recognize the page?
Make sure you're on a track URL (soundcloud.com/artist/track), not the home feed. Wait 2-3 seconds or click Retry.

Download fails with error?
Disable ad blockers for soundcloud.com and *.sndcdn.com. Enable popups and redirects in Chrome settings.

Need higher quality?
SoundCloud doesn't stream 320kbps. The extension automatically uses original uploaded files when available.

Frequently Asked Questions

Is it legal to download from SoundCloud?

Only download content you own or have permission to save. Respect artists' rights and SoundCloud's terms of service.

Does it work on mobile?

No, this is a Chrome desktop extension. Mobile browsers don't support extensions.

Is it really free?

Yes: standard full-track and collection downloads, bulk downloading, folders, formats available from the source, cover art and metadata are free forever. Player Tools has a 7-day / 20-loop trial, and its unlimited loops, exports, EQ and Likes Explorer require the one-time Pro purchase.

Do I need a SoundCloud account?

No login required for public tracks. You need to be logged in only for your own likes or private content.
