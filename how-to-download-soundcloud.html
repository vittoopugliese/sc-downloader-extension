How to Download SoundCloud Tracks, Playlists & Likes (Free Guide)

Updated: September 2026 — Learn how to download SoundCloud tracks, playlists, and entire collections using our free Chrome extension. No login required for public tracks.

Ready to start downloading?

Install Free Chrome Extension

Download Single SoundCloud Tracks

  1. Install the SoundCloud Track Downloader extension
  2. Go to any SoundCloud track page (e.g., soundcloud.com/artist/track-name)
  3. Click the orange download button in the action bar (next to Like/Repost/Share)
  4. The track downloads to your chosen folder with cover art and metadata

Download SoundCloud Playlists in Bulk

  1. Open any SoundCloud playlist or album page
  2. Click the extension icon or use the inline download button
  3. Choose how many tracks: 10, 25, 50, 100, 200, or All
  4. Select your download folder (optional)
  5. Click Download — files save automatically as they complete

Pro tip: You can close the popup or switch tabs. Downloads continue in the background.

Download Your SoundCloud Likes

  1. Go to soundcloud.com/you/likes (requires login)
  2. Or visit any user's public likes page: soundcloud.com/username/likes
  3. Click the download button and select the number of tracks
  4. All liked tracks download to a numbered folder

Download All Tracks from a SoundCloud Artist

  1. Visit soundcloud.com/artist-name/tracks
  2. Click "Download tracks" button
  3. Select which tracks you want from the list
  4. Start bulk download

Audio Quality & Formats

The extension downloads tracks in their available streaming quality:

  • AAC HLS 160k — SoundCloud's standard streaming format (~50-80 MB/hour)
  • Original files — When artists enable downloads, you get WAV/FLAC/high-quality MP3
  • No artificial quality loss or re-encoding

Troubleshooting Common Issues

Extension doesn't recognize the page?
Make sure you're on a track URL (soundcloud.com/artist/track), not the home feed. Wait 2-3 seconds or click Retry.

Download fails with error?
Disable ad blockers for soundcloud.com and *.sndcdn.com. Enable popups and redirects in Chrome settings.

Need higher quality?
SoundCloud doesn't stream 320kbps. The extension automatically uses original uploaded files when available.

Frequently Asked Questions

Is it legal to download from SoundCloud?

Only download content you own or have permission to save. Respect artists' rights and SoundCloud's terms of service.

Does it work on mobile?

No, this is a Chrome desktop extension. Mobile browsers don't support extensions.

Is it really free?

Yes. All features are completely free — bulk downloads, looper, tempo control, and folder selection.

Do I need a SoundCloud account?

No login required for public tracks. You need to be logged in only for your own likes or private content.
